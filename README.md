# СберHelp: Интеллектуальная система маршрутизации клиентских обращений

Интеллектуальный помощник на базе больших языковых моделей (LLM) для автоматизации первой линии технической поддержки СберТех. Система анализирует неструктурированные запросы, уточняет контекст и маршрутизирует обращение: решает типовые задачи автономно или передает их живому оператору с готовым резюме проблемы.

## 1. Проблема

Высокая нагрузка на операторов первой линии поддержки обусловлена большим объемом неструктурированных запросов пользователей (например: «ничего не работает», «ошибка при переводе»). Необходимость многократных ручных уточнений увеличивает среднее время обработки тикета (SLA) и снижает показатель удовлетворенности клиентов (CSAT).

## 2. Архитектура решения

Система реализует многоэтапный диалоговый сценарий для точной классификации инцидента:

1. **Первичный анализ:** Получение неструктурированного запроса от пользователя.
2. **Контекстуализация:** Генерация системой до 3 уточняющих вопросов для сужения области проблемы.
3. **Валидация:** Формирование системой краткого резюме запроса («Я правильно понял, что проблема заключается в...») и ожидание подтверждения пользователя.
4. **Маршрутизация:** На основе подтвержденного контекста система принимает одно из трех решений:
   - **Автономное решение:** Предоставление готовой инструкции, если проблема типовая и алгоритмизированная.
   - **Приоритетная эскалация:** Мгновенная передача диалога оператору при выявлении паттернов мошенничества или критических сбоев.
   - **Стандартная эскалация:** Передача тикета в общую очередь поддержки с системной пометкой «Требуется вмешательство человека» (в случае невозможности точной классификации ИИ).

## 3. Технологический стек

- **Frontend:** HTML5, CSS3, Vanilla JavaScript. Адаптивный интерфейс, реализованный в соответствии с гайдлайнами СберТех (цветовая палитра: черный, зеленый, голубой).
- **Backend:** 
  - Java (Maven) — основная бизнес-логика и управление сессиями.
  - Python (`app.py`) — микросервисный слой для интеграции с внешним API нейросети.
- **AI/ML:** GigaChat API. Использование методологии Prompt Engineering для жесткой регламентации стиля ответов и логики классификации.

## 5. Инструкция по развертыванию и запуску
5.1. Клонирование репозитория

git clone https://github.com/axasdel/sber_help_hackaton.git
cd sber_help_hackaton

5.2. Запуск Backend

Способ А (через IDE, рекомендуется):
Откройте директорию backend в VS Code или IntelliJ IDEA и запустите основной класс приложения или файл app.py через встроенный отладчик (кнопка Run).

Способ Б (через терминал):

cd backend
# Для Java-приложения:
./mvnw spring-boot:run
# Или для Python-интеграции:
python3 app.py

5.3. Запуск Frontend
Для корректной работы CORS-политик рекомендуется запускать фронтенд через локальный HTTP-сервер:

cd frontend
python3 -m http.server 8080
